# 🛡️ MailGuard AI

### AI-Powered Email Spam Detection System

MailGuard AI is a machine-learning-powered web application that analyzes email content and classifies messages as **Spam** or **Safe**.

The project combines a Python machine learning model with a Flask web application and a modern interactive frontend.

## 🧠 How It Works

The application follows a simple workflow:

```text
User enters email
        ↓
Email sent to Flask backend
        ↓
Machine Learning model analyzes content
        ↓
Prediction generated
        ↓
Spam / Safe result displayed

🎯 Why MailGuard AI?
Spam and malicious emails are a common cybersecurity problem.
MailGuard AI provides a simple way for users to analyze suspicious email content using machine learning without requiring complicated security tools.
🌌 Interactive UI
The application includes an interactive 3D background with:
- Floating elements
- Depth effects
- Smooth animations

This creates a more engaging experience while keeping the interface simple and easy to use.
